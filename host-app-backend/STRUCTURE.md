# Пример структуры проектра

```
src/main/java/dev/hostapp/backend
│
├── App.java                    # точка входа, запуск приложения
│
├── controller/                 # REST API
│   └── ItemController.java
│
├── model/                      # модели / сущности
│   └── Item.java
│
├── service/                    # бизнес-логика
│   └── ItemService.java
│
└── repository/                 # получение и сохранение данных
    └── ItemRepository.java
```
